# PetCare
Веб-приложение для учёта здоровья и рациона домашнего питомца. Помогает владельцам кошек и собак контролировать рацион, вес и график вакцинации без необходимости регистрации, серверов и сложных настроек, решая проблему фрагментарного учёта здоровья питомца.

## Основные возможности
* **Учёт профиля питомца** - хранение данных о породе, возрасте и текущем весе;
* **Отслеживание прививок** - напоминания о плановой и экстренной вакцинации, расчёт даты следующей ревакцинации;
* **Динамика веса** - наглядные линейные графики изменения массы тела (на базе **[Chart.js](https://github.com/chartjs/Chart.js)**);
* **Приватность и скорость** - данные хранятся локально в браузере через LocalStorage, приложение работает без бэкенда и загружается мгновенно.

## Установка
Для запуска проекта локально вам потребуется система управления версиями **[Git](https://github.com/git/git)** и установленный пакетный менеджер **[Bun](https://github.com/oven-sh/bun)**.
1. Клонируйте репозиторий:
```bash
git clone https://github.com/akpd806/petcare.git
```
2. Перейдите в папку проекта:
```bash
cd petcare
```
3. Установите зависимости:
```bash
bun install
```
4. Запустите сервер разработки:
```bash
bun run dev
```

## Использование
После запуска откройте в браузере адрес, указанный в терминале *(обычно `http://localhost:4321`)*.
1. **Создание профиля** - на главной странице добавьте питомца, указав его кличку, вид, породу и текущий вес;
2. **Кормление** - перейдите в раздел "Кормление", чтобы увидеть рассчитанную суточную норму. Отмечайте каждый приём пищи кнопкой "Покормлен";
3. **Здоровье** - в разделе "Прививки" внесите дату последней вакцинации;
4. **Графики** - регулярно добавляйте замеры веса в разделе "Вес", чтобы отслеживать динамику на интерактивном графике.
