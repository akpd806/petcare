## Дизайн-система

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--accent` | `#FF7A1A` | `#FF8A3D` | основной акцент |
| `--accent-deep` | `#D9560B` | `#FFA45C` | текст / иконки на акценте |
| `--accent-soft` | `#FFEEDD` | `#3B2410` | подложки чипов и кнопок |
| `--hero` | `#FFB25E -> #FF8A3D -> #FF6B35` | идентично светлой | градиент карточки питомца |
| `--ok / --warn / --bad / --info` | `#16A34A / #B45309 / #DC2626 / #2563EB` | осветлённые | семантика статусов |
| `--teal / --violet` | `#0D9488 / #7C3AED` | осветлённые | график и статистика веса |
| Фон / поверхность | `#F3EDE4 / #FFFFFF` | `#161210 / #221C15` | нейтральные тёплые |
| Чернила / приглушённый | `#26190E / #8A7D6E` | `#F4ECE1 / #A2937F` | текст |

Типографика: Шрифты **Manrope** (текст) и **Unbounded** (логотип). Скругление по умолчанию - 16 px. Контрольные точки: 360 / 768 / 1280 px.

## Экраны и элементы управления

| Экран | Ключевые элементы |
|---|---|
| Главная | карточка питомца, баннеры напоминаний, кольцо "съедено/норма", ближайшее кормление и прививка, мини-график |
| Кормление | суточная норма, расписание приёмов, журнал за день, столбцы за неделю |
| Прививки | поиск, фильтры статусов, карточки с историей доз, форма добавления |
| Вес | график (3 / 6 / 12 мес), породный диапазон, статистика, история, форма замера |
| Профиль | аватар и окрас, форма данных, удаление питомца |
